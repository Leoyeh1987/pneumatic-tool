# 氣壓迴路圖工具 
氣壓迴路圖工具 v1.6.2 介紹

教學影片連結:https://youtu.be/clmNWubcVEM
網址：https://leoyeh1987.github.io/pneumatic-tool/

這是一套在瀏覽器裡畫氣壓迴路圖的工具，給自動化設備工程師用。從畫迴路、挑元件、模擬動作、檢查錯誤，到出明細表和列印圖面，都在同一個網頁裡完成。整套只有一個 HTML 檔，不用安裝，打開就能用。

主要功能

一、繪圖

符號照 JIS B 0125-1／ISO 1219-1 正式畫法，也對照過 SMC、Festo 型錄的畫法。
元件分類完整：氣源處理、方向閥、氣缸、夾爪、真空、感測器、點膠元件等。
拉線時會自動避開元件。接點太近時會擋住，避免接錯。
線拉到現有管線上，元件會自動插進去。
可以多選元件和管線，一次改管徑、類型。
先導／控制管路依 ISO 規定畫成虛線。

二、模組庫（116 個常用迴路）

涵蓋水平直線、垂直升降、夾爪、真空吸取、旋轉、安全斷氣等常見應用。
選好就能插入，還可以自動接到主氣源。
可以把自己常用的迴路存成「我的常用模組」。

三、連座產生器

輸入連數和盲板數，就會自動排好電磁閥島。
排氣接上下兩條線並自動裝消音器，供氣接中間那條。
盲板的接點和電磁閥相同，空站直接蓋上。

四、型號自動抓規格

輸入 SMC、Festo、AirTAC 的氣缸型號，例如 CDQ2B32-50、DSBC-32-100、MAL20X100，會自動帶出缸徑、行程、桿徑。
雙軸缸會自動把出力和耗氣量乘兩倍。
雙出桿氣缸的推力、拉力都會扣掉活塞桿面積。

五、動作模擬

直接點電磁閥切換，或輸入動作順序（例如 1A1+ 1A1-）自動跑。
管路依狀態變色，分成加壓、排氣、真空。
氣缸上方即時顯示推力和拉力。
可以產生位移-步驟圖，並診斷卡住或沒動作的原因。

六、迴路檢查

自動找出沒接的接點、沒有氣源、排氣口沒裝消音器等問題。
已確認沒問題的項目可以排除，之後就不會再出現。

七、ISO 1219-2 元件代號

按一下就能把整張圖重新編號：1A1 氣缸、1V1 方向閥、1V2 調速閥、0Z1 氣源處理。
動作順序裡的代號會一起更新。

八、點膠元件（18 種）

包含膠桶、馬達膠桶、螺桿閥、雙液螺桿閥、雙液混合閥、靜態混合管、齒輪泵、螺桿泵、噴射閥、針頭等。
雙液閥的出口剛好對上靜態混合管，可以直接接。

九、明細表與計算

依圖面自動產生明細表，可以填品牌和型號。
匯總表改了之後，會同步回圖上的元件。
在明細表點零件編號，會跳回圖面標出那個元件。
有耗氣量、出力表、I/O 表、安全表。

十、輸出

可以自由拖曳列印範圍，左上角標題框大小固定。
可以存成 PDF、PNG、SVG。
圖面存成 JSON，之後能再打開編輯。
優點
免安裝、免費、離線可用。 單一網頁檔，公司電腦也能直接開。不用買 FluidSIM 或 Automation Studio 的授權。
貼近實務。 模組庫、連座、型號抓規格、出力計算，都是照設備設計的實際流程做的，不只是畫圖。
畫完就能驗證。 模擬加迴路檢查，在出圖前就能抓出接錯的管路和缺少的元件。
一張圖產出整套文件。 迴路圖、明細表、耗氣量、I/O 表一起產生，不用另外整理 Excel。
符號標準統一。 依 JIS／ISO 正式畫法，跟 SMC、Festo 型錄一致，給客戶或廠商看都不會有落差。
點膠和氣壓畫在同一張圖。 點膠和灌膠設備的供膠系統可以跟氣壓迴路一起表達。
持續更新。 有教學影片和改版說明，新功能會跟著現場需求加入。
